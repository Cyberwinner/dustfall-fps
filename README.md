DUSTFALL is a round-based tactical FPS built on three.js: one player against four bots on an original foundry-yard map with three lanes and two bomb sites. Win rounds by eliminating the other team or by the bomb objective — plant it, defend it, or defuse it. Between rounds, spend the money you earned on rifles, SMGs, shotguns, armour and grenades. Gunplay rewards standing still and aiming: recoil and spread punish spraying on the move, and headshots pay 2.5×.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser with WebGL 2.
